# MARG Scoring Engine — Python Dependencies
#
# This project uses ONLY Python standard library modules.
# No third-party packages are required.
#
# Standard library modules used:
#   - math         (isfinite, nan, inf detection)
#   - dataclasses  (RouteInput, RouteScore, DetailedRouteScore)
#   - typing       (List, Optional)
#   - unittest     (test runner)
#   - json         (demo output formatting)
#   - sys          (exit code in test runner)
#
# Python version: >= 3.8
#
# To run tests:
#   python test_scoring.py
#   python -m pytest test_scoring.py -v
#
# To run the demo:
#   python demo.py
